# BoticaSysFx: sistema de botica (proyecto académico)

Aplicación de escritorio para gestionar una botica, hecha con **Java, JavaFX y Spring Boot** en la Universidad Peruana Unión.

## Qué incluye
- Inicio de sesión de usuarios.
- Gestión de productos y medicamentos.
- Modelo de datos: categorías, marcas, clientes, proveedores, usuarios y carrito de venta.
- Reportes con JasperReports.
- Componentes propios de interfaz (autocompletado, avisos tipo toast, tablas).

## Stack
Java · Spring Boot 3.3 · Spring Data JPA · JavaFX · SQLite · JasperReports · Maven
